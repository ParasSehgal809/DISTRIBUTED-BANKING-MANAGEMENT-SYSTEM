How Two-Phase Commit (2PC) Operates in this System

1 Phase 1: Prepare Phase
  • Coordinator writes PREPARING to coordinator_wal.
  • Sends PREPARE request to debit branch and credit branch.
  • Participants acquire Strict 2PL Exclusive Locks (X).
  • Debit branch verifies funds (balance >= amount).
  • Participants write PREPARED in branch_wal.
  • Participants reply with VOTE_COMMIT or VOTE_ABORT.
2 Phase 2: Commit / Abort Phase
  • If all participants voted COMMIT: Coordinator durably writes GLOBAL_COMMIT to central WAL.
  • If any voted ABORT: Coordinator writes GLOBAL_ABORT.
  • Coordinator sends decision to all branch nodes.
  • Branches update balances, append to local ledger, write to local WAL, and release locks.
  • Coordinator logs transaction final state as COMMITTED.
